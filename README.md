# SpeedDialSorter_rust / CSV電話帳処理ツール

CSV形式の電話帳データを整理・クリーニングし、ナカヨ電話機用のフォーマットに変換するWindowsデスクトップツールです。

## 機能

- **名前クリーニング**: NFKC正規化、全角/半角変換、会社名称の除去
- **メモリ番号整列**: 0000〜9999の4桁ゼロ埋め・重複マージ
- **グループ9（迷惑電話）抽出**: 迷惑電話番号を別ファイルへ分離
- **ナカヨ電話帳形式出力**: ナカヨ電話機インポート用17列CSV（UTF-8 BOM）
- **ナカヨ迷惑電話形式出力**: ナカヨ電話機用迷惑電話ファイル（Shift-JIS / 頭詰め）
- **重複電話番号検出**: 重複している電話番号をレポート出力
- **名前・ヨミガナ文字数チェック**: 文字幅上限を超えた項目をレポート出力

## 出力ファイル

| ファイル名 | 内容 | 文字コード |
|---|---|---|
| `*_processed_日時.csv` | 処理済み電話帳（全データ） | UTF-8 BOM |
| `*_ナカヨ電話帳_日時.csv` | ナカヨ電話帳形式（17列） | UTF-8 BOM |
| `*_迷惑電話_ナカヨ形式_日時.csv` | ナカヨ迷惑電話形式（頭詰め） | Shift-JIS |
| `*_迷惑電話_日時.csv` | 迷惑電話（グループ9）抽出 | UTF-8 BOM |
| `*_重複電話番号_日時.txt` | 重複電話番号レポート | UTF-8 |
| `*_名前文字数超過_日時.txt` | 名前文字数超過レポート | UTF-8 |
| `csv_processor.log` | 処理ログ | UTF-8 |

## ビルド

```
cargo build --release
```

実行ファイルは `target/release/csv_phonebook.exe` に生成されます。  
`icon.ico` を exe と同じフォルダに置くとウィンドウアイコンとして使用されます。

## 動作環境

- Windows 10 / 11
- Rust 1.75以降
